# uap6:AllowExecution

Indicates whether the contents of the package will be allowed to execute.

## Element hierarchy

**[`<Package>`](element-f-package.md)**  
&nbsp;&nbsp;&nbsp;└─ [`<Properties>`](element-f-properties.md)  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;└─ **`<uap6:AllowExecution>`**  

## Syntax

```xml
<uap6:AllowExecution>
  boolean
</uap6:AllowExecution>
```

## Value

A boolean value.

## Attributes

None.

## Child elements

None.

## Parent elements

| Parent element | Description |
|-|-|
